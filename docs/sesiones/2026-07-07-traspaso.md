- **Instalador de Windows generado**: `pnpm --filter @gluuh/desktop dist` →
  `apps/desktop/dist-instalador/Gluuh TPV Setup 0.1.0.exe` (~98 MB, NSIS).
  `dist-instalador/` ignorado en git. **Sin firma** (SmartScreen avisará).
- **IP/URL del servidor configurable**: el desktop lee `config.json`→`servidor`
  en runtime (precedencia config > GLUUH_URL > localhost), sin re-empaquetar.
- **Editable desde Configuración**: puente `window.gluuh.leerConfigTerminal/
  guardarConfigTerminal` (preload + IPC + `guardarConfig` escritor); componente
  `components/config-terminal.tsx` en la config de impresión (IP servidor +
  carpeta backup). Al cambiar el servidor, la app recarga sola. En navegador,
  avisa que solo se configura desde el escritorio.
